# AnimieVault

Animie Website built with React, TypeScript, and Vite.

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)

### Installation
1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
